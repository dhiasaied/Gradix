Documentation

How to explore colors, inspect collections, and build layered gradients in Gradix.

Explore palette

Open Explore to browse 120 curated colors. Click any swatch to copy its HEX value. Filter by Neutrals, Reds, Oranges, Yellows, Greens, Blues, Purples, or Accents.

Press Ctrl+K (or ⌘K) anywhere to search by name, hex, or category.

Collections

Visit Midnight Sapphire to preview a curated gradient, shuffle seeds, toggle fullscreen, copy color stops, and export CSS. Related colors at the bottom use the same copy-on-click behavior.

Create studio

In Create you can stack radial, linear, and conic layers with blend modes, noise, and grain. Use the output tabs for CSS, Tailwind, or artistic prompts. The ⋮ menu exports CSS, copies the prompt, or resets layers.

  • Add or delete layers from the Layers panel
  • Pick library colors to apply to the active layer’s first stop
  • Zoom the preview with the canvas controls

CSS gradients reference

Gradix outputs standard CSS gradients. For the full language reference, see the MDN gradient documentation.
